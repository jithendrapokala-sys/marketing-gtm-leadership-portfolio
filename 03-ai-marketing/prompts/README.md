# Prompt Library

Reusable templates. Replace `{{placeholders}}` with your own values. Each template states its inputs, output format and guardrails, so results are consistent across the team.

| Template | Use |
|---|---|
| [account-research-brief.md](account-research-brief.md) | One-page brief on a target account for sellers |
| [persona-outreach.md](persona-outreach.md) | First-touch outreach email per buying-committee persona |
| [content-repurposing.md](content-repurposing.md) | Turn one long-form asset into multi-channel content |
