# Positioning & Messaging Canvas

## 1. Positioning Statement

> For **[target customer]** who **[need / problem]**, **[product]** is a **[category]** that **[key benefit]**. Unlike **[main alternative]**, we **[key differentiator]**.

## 2. Positioning Building Blocks

| Block | Questions to answer |
|---|---|
| Competitive alternatives | What would the customer do if we didn't exist? (Competitor, in-house build, spreadsheet, do nothing) |
| Unique capabilities | What can we do that the alternatives can't? |
| Value | What does each capability mean in business terms (revenue, cost, risk, time)? |
| Proof | What evidence backs it up (case study, metric, certification, reference)? |
| Best-fit customers | Who cares most about this value? |
| Market category | What frame helps buyers understand us fastest? |

## 3. Message House

```
                 ┌───────────────────────────────────┐
                 │  Umbrella message (one sentence)  │
                 └───────────────────────────────────┘
   ┌───────────────┐   ┌───────────────┐   ┌───────────────┐
   │   Pillar 1    │   │   Pillar 2    │   │   Pillar 3    │
   │  (e.g. Cost)  │   │ (e.g. Speed)  │   │ (e.g. Risk)   │
   ├───────────────┤   ├───────────────┤   ├───────────────┤
   │ Proof points  │   │ Proof points  │   │ Proof points  │
   └───────────────┘   └───────────────┘   └───────────────┘
   ─────────────── Foundation: credibility & trust ───────────────
```

## 5. Test Before You Scale

- Run 2–3 message variants in LinkedIn ads and email subject lines
- Measure meeting-acceptance rate, not just clicks
- Feed objections from sales calls back into the canvas every month
